Add a "Share App" button to the mobile view of the Milōn web app.
This is a simple feature — do not overcomplicate it.

═══════════════════════════════════════════════════════════════
WHAT TO BUILD
═══════════════════════════════════════════════════════════════

1. A Share button visible only on mobile screens
2. A share sheet modal with three options:
   - Share via WhatsApp
   - Share via Email
   - Copy link
3. A "How to install this app" instruction screen
   accessible from the share modal

═══════════════════════════════════════════════════════════════
THE SHARE BUTTON
═══════════════════════════════════════════════════════════════

Position: Fixed, bottom right of the screen
Only visible on screens below 768px width
Use CSS: @media (max-width: 768px) { display: flex } 
         @media (min-width: 769px) { display: none }

Button style:
- Circular floating action button (FAB)
- 52px × 52px
- Background: your app's accent color
- Icon: a share icon (use the lucide-react Share2 icon)
- Subtle drop shadow
- z-index: 50 so it floats above content
- Bottom: 24px, Right: 24px

Do not show this button if the user is already viewing 
the app in standalone mode (already installed as PWA).
Check with:
  const isInstalled = window.matchMedia(
    '(display-mode: standalone)'
  ).matches;
If isInstalled is true, hide the share button entirely.

═══════════════════════════════════════════════════════════════
USE NATIVE SHARE API IF AVAILABLE
═══════════════════════════════════════════════════════════════

Modern mobile browsers support the Web Share API.
If available, use it — it opens the phone's native 
share sheet which feels the most natural.

const handleShare = async () => {
  
  const shareData = {
    title: 'Milōn — Financial Intelligence',
    text: 'Track your business financial health with 31 ratios across Profit, Assets, Financing and Cash.',
    url: window.location.origin
  };

  // Use native share if available (most modern mobile browsers)
  if (navigator.share && navigator.canShare(shareData)) {
    try {
      await navigator.share(shareData);
      return; // Native share handled it — don't show modal
    } catch (error) {
      if (error.name === 'AbortError') return; // User cancelled
      // Fall through to custom modal if native share fails
    }
  }
  
  // Fallback: show the custom bottom sheet modal
  setShareModalOpen(true);
};

So the flow is:
1. User taps Share button
2. If navigator.share is available → native share sheet opens
3. If not available → custom bottom sheet modal opens
4. The custom modal is the fallback for older browsers 
   and desktop browsers that don't support Web Share API

COMPONENT STRUCTURE

Create these files:

  - Full screen overlay
  - iPhone and Android tab instructions

/src/components/share/index.js
  - Exports all three

Import ShareButton into your main App.jsx or layout 
component and render it at the root level so it floats 
above all pages:

// In App.jsx or Layout.jsx
import { ShareButton } from './components/share';

return (
  <div>
    {/* your existing app */}
    <ShareButton appUrl={process.env.NEXT_PUBLIC_APP_URL} />
  </div>
);

═══════════════════════════════════════════════════════════════
BOTTOM SHEET ANIMATION
═══════════════════════════════════════════════════════════════

The modal should animate in from the bottom.
Use a simple CSS transition — no animation library needed:

// Closed state
transform: translateY(100%);
opacity: 0;

// Open state  
transform: translateY(0);
opacity: 1;

transition: transform 0.3s ease-out, opacity 0.2s ease-out;

Add a dark overlay behind the modal:
background: rgba(0, 0, 0, 0.5);
Tapping the overlay closes the modal.

The modal itself should have:
- White background
- Border radius 16px on top left and top right only
- Padding: 24px
- A small drag handle at the top centre:
  A 32px wide, 4px tall, rounded pill in a muted grey
  This is a visual affordance that it can be swiped down
  (you don't need to implement swipe-to-close, 
  just the visual handle)
- Max height: 80vh with overflow scroll if content is taller
