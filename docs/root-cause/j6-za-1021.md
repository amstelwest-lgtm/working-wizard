## 1. Hand to Advisor returns `forbidden`

**Cause.** The browser toast is the JSON `error` from `supabase/functions/owner-handoff/index.ts` (the 403 at the `callerMayHandOff` check). `callerMayHandOff` (`src/lib/owner-handoff.ts`) allowed only `clients.owner_user_id` or a `client_memberships` row. A practice editor who can open the file (`is_client_writer`: active practice assignment and `practice_can(..., 'edit')`) is neither of those on a firm file, so the function returned `{ error: "forbidden" }`. That 403 is an access miss. It is not the right answer for a no-plan or expired-trial firm.

`starter-trial-gate` / `cardlessTrialAiBlock` return `starter_trial_ended` and “Your trial has ended, choose a plan”. They are not on this path. `agent-advisor` and `agent-dispatch` return `forbidden` only for a bad service-role bearer; `agent_invoke` does not send that body back to the browser. “Couldn't check billing” is the firm billing gate (Eng2) and a different client URL.

Next moves (`MoveHandTo` in `src/components/hand-to-menu.tsx`) reverted the label on the failed refresh and did not keep an inline error, so the row went back to plain “Hand to”. The action plan toasted the raw word and showed “Couldn't hand this over · Retry” because `fail()` in `src/lib/owner-handoff-client.ts` replaced the refresh error with that generic line.

**Why US passes.** The US operator matches `clients.owner_user_id`, so `callerMayHandOff` was already true.

**Fix.** `owner-handoff` also allows `is_client_writer`. The 403 sentence names the access miss. Trial copy is used only when the server returns the trial code. Next moves keeps that sentence and Retry.

**Verification.** `pnpm test:j6-za-1021`. A practice editor may hand off; a stranger may not. `handoffFailureMessage("forbidden")` is not the raw word.

**Edge changed.** `owner-handoff` only. No change to `ask-ai`, `milon-bot`, `brain-propose`, or `brain-deliverable-draft`.
